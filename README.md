# 城市经营日报

本版可托管在 GitHub Pages。页面在当前浏览器解析原始 Excel，将报表和手动修改保存到该浏览器。每位使用者从「数据接入」选择两份底表及相应统计日。漏斗表确认为单日统计后，可汇总生成周报。

把压缩包解压后的内容放到 GitHub 仓库的根目录。在仓库 Settings → Pages 的 Build and deployment 中选择 Deploy from a branch，再选择 main 分支与 / (root)。访问控制由 GitHub Pages 管理，仓库只应包含应用文件。

使用 Chrome 或 Edge 打开发布后的站点。报表支持三级搜索、慢闪店过滤、异常编辑和 PNG 导出。
